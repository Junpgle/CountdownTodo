# 第二十轮验收：清单草稿隔离与可靠保存

日期：2026-10-19（北京时间）。状态：**实现完成，等待用户验收。**

本轮将退出保护和可靠保存扩展到待办清单式编辑流程。未保存的对象先在独立副本上修改，只有持久化成功后才替换页面或内存中的来源对象；失败时保留输入和可重试状态。

## 实际变更

- 新建待办页记录表单基线；有草稿时返回可继续填写、放弃或保存并退出。手动保存失败留在页面，重试沿用同一待办 ID。共享新建页没有真实待办保存回调时，不再以空回调报告成功。
- 首页、待办列表、文件夹、搜索、帮助、macOS 菜单、课程和规划入口接入或转发明确的待办保存结果。首页先确认本机待办落盘，再更新团队、共享快照、提醒和小组件；附属更新失败单独显示警告。
- 文件夹管理对待办和分组使用深拷贝，父级保存成功后再提交本地页面状态；移动操作不会提前修改传入对象。文件夹内新建待办在保存成功后才进入文件夹列表。
- AI识别确认批次为每项保留稳定 ID。首页落盘前不提前更新待办列表；保存失败后确认结果仍在，重试按 ID 合并。最后一项保存失败时会进入可重试的完成页。
- AI待办操作的编辑、选择、分类和忽略先操作独立副本，聊天记录写入成功后再替换内存操作。首页快速添加也沿用稳定 ID，并复用明确保存结果。
- 保留第十九轮编辑页的来源对象保护，并补充回归覆盖。
