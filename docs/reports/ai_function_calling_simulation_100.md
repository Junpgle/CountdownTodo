## 数据预算与保真

| 范围 | 当前行为 |
| --- | --- |
| 列表 | 默认 10 条，明确指定时最多 50 条；has_more 表示存在后续记录，模型仅在用户要求更多/全部或答案确有需要时翻页 |
| 单次模型工具结果 | 最多 8,000 个序列化字符；超过时缩减明细和长文本，标记 context_truncated / omitted_fields |
| 同一用户轮次 | 工具结果预算 24,000 字符，最多 4 轮查询 / 8 次调用；到达上限后依据已读取范围回答 |
| 重复查询 | 同轮同条件复用前次结果，只回传引用；失败允许重试，下一用户轮次重新读取 |
| 历史查询 | 仅最近 3 条含查询结果的消息，每条最多 2,000 字符，保留汇总与少量对象 ID |
| 历史思考 | 保存在对话供用户展开，不再随新一轮请求回传；当前工具轮次按服务商需要保留 reasoning_content |
| 汇总 / 分页 | 总额、数量、时长保持完整筛选范围；缩减明细后 next_offset 按模型实际收到的条数调整 |
| 对话调用记录 | 保留 App 原始返回，可展开查看完整参数和数据；模型接收精简副本 |

预算覆盖工具结果。用户消息、正式回复、系统提示和工具说明另外计入模型输入，因此这里的字符限制不等同于整个请求的 Token 上限。
