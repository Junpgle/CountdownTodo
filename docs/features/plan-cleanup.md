# 已完成待办的剩余规划收尾

待办提前完成后，可以主动取消它尚未开始、没有投入的个人规划。待办完成时不会自动取消规划。

## 入口与操作

在已保存完成状态的待办编辑页「计划安排」中选择「处理剩余规划」，或者从「待规划」页的更多菜单进入「已完成待办的剩余规划」。总清单支持搜索、文件夹筛选和分页，同名待办按各自记录独立展示。

打开具体待办后，核对日期、时段、状态和提醒，取消勾选需要保留的安排，再点击底部「取消选中N段」。确认框列出日期范围和区间并集分钟数；返回核对不会写入数据。

首次只勾选当前加载且合格的规划，后续分页不自动勾选。一次最多处理50段。重新核对后需要重新选择。

## 保护规则

- 仅处理当前账号内，已完成、未删除、无冲突的个人待办及其明确选中的规划。
- 规划必须尚未开始，状态为待执行、已提醒或延后，时长合法且没有实际投入或关联记录。
- 关联团队待办的剩余规划、正在专注或暂停的任务、历史规划、有投入及无法确认关联的数据均不能批量处理。
- 确认期间出现新增、修改、删除、投入变化、完成状态撤回或开始时间到达时，整批拒绝，要求重新核对。

规划取消与同步日志在同一个事务中保存，任一步失败全部回滚。响应丢失后的同一请求，仅在所有目标都完整匹配本次已保存结果时识别成功，不重复写日志或递增版本。

## 提醒、日历与历史

成功后只撤下选中规划的应用提醒，保留番茄和习惯来源。提醒更新失败会单独显示重试，重试不会再次取消规划。排队的旧规划提醒会再次检查数据库状态；只有待执行、已延后和已提醒状态保留开始提醒。已取消状态不能被旧提醒维护改回已提醒。

手机日历导出副本不会随本次操作删除，仍可能被忙闲查询视为占用。界面提供「前往日历同步核对」，不承诺系统日历或其他设备已经撤销。

历史专注、时间记录、备注、番茄配置、提醒配置和日历ID保持原值。取消的区间分钟数只表示应用内取消的规划，实际可用时间以重新查找为准。重新打开待办不会自动恢复已取消规划。
