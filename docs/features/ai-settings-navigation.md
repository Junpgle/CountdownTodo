# AI 设置直达

助手可查询当前应用设置目录，通过入口卡片进入对应页面并定位控制项。
目录位于 `lib/services/app_settings_catalog.dart`，包含全部设置页面、平台专属项、首页与侧栏每个模块，以及记账、题目、番茄钟和标签管理入口。

## 行为

- Function Calling 使用 `propose_settings_navigation`，文本协议使用 `[SETTINGS_START]{"targets":["入口ID"]}[SETTINGS_END]`；两者使用同一份目录。
- 模型只返回稳定 ID；标题、路径、平台限制和路由由应用校验，最多展示 3 张相关卡片。无效或当前平台不可用的 ID 不生成入口。
- 点击卡片后自动滚动并高亮设置；学期日期、修改密码、自定义模型和番茄钟时长可打开已有编辑面板，识别提示词会展开高级配置。
- 导航不修改开关、选择模式、提交表单、同步或删除数据。编辑和保存仍由用户操作，原有未成年人模式授权检查继续生效。
- 依赖当前模式、登录状态或设备能力的控制项，优先定位；未显示时定位所在页面的前置选项并提示条件，不自动改变模式。
- 历史消息保存入口 ID，并明确告诉模型卡片展示不代表设置已经修改。返回聊天页后重新读取助手提示词、思考和模型配置。

## 全局搜索

全局搜索的“全部”和“设置”范围从同一目录生成设置结果，使用名称、搜索别名和路径匹配关键词。设置结果点击后复用同一页面工厂，自动定位控制项并保留从结果卡片展开、返回搜索结果的转场。旧的手工设置清单已移除，原有常用搜索词合并到目录，避免重复和漂移。

`settings_global_search_test.dart` 验证所有当前可用的设置都能被实际查询命中、别名和多关键词检索、范围与平台过滤及结果去重；`settings_global_search_flow_test.dart` 验证窄屏和桌面搜索、定位、返回流程。

## 维护

新增或更名设置时，同时维护目录中的 ID、可见标签、搜索别名和平台范围，并在 `AiSettingsNavigation.pageFor` 中维护页面路由。已有 ID 应保持稳定。
特殊子页面、折叠区或编辑弹窗需要显式处理初始导航目标；不得通过模拟点击保存、同步等操作来定位。

`app_settings_catalog_test.dart` 检查目录唯一性、页面覆盖、平台过滤以及标签与实际页面源码的对应关系。
`settings_focus_page_test.dart` 覆盖长列表、异步加载、动态标签、前置条件和销毁；`settings_destination_flow_test.dart` 与卡片测试覆盖实际页面、编辑弹窗、窄宽屏以及导航不更改设置。
