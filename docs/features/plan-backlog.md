# 待规划清单

规划时间轴顶栏的“待规划”入口打开独立清单，继承当前日期。历史日期会切到今天并说明；时间轴仍全天24小时一屏，保留拖动新建、移动、缩放与撤销。统计、刷新位于“更多”；窄屏和大字体下前后一天也收进“更多”，日期仍可点击选择。无冲突时不保留空按钮占位。

清单默认“待安排”，可切换“已有安排”，并按标题和文件夹筛选。标题按字面匹配，百分号和下划线不会变成通配符。无效／已删除文件夹归到未分组。截止分组以目标日期为准，首屏50项，按需加载更多。

## 判定口径

- 只选当前成员视角未完成、未删除、UUID和标题非空的真实待办。独立协作使用当前成员的完成覆盖值；共同协作使用全局值。冲突任务只提供查看处理。
- 重复系列先从合格的未完成期次选择目标日代表，再判断安排和分页。同名不同UUID独立；其他期次的规划不冒充本期安排。
- 未删除、有效区间、结束仍晚于当前时刻，且状态为planned／reminded／delayed／focusing的真实规划归入已有安排，查询所有日期，包括跨午夜。历史／取消／漏做／跳过不占此口径。
- 本机仍在focusing阶段的明确绑定任务，包括暂停，显示当前专注状态。矛盾绑定与坏规划显示安排需检查；无法读取／无法确认的状态显示错误，不能等同空清单。
- 普通截止、日期待办、物理创建时间不等于已有安排。合法未来旧式同日执行区间沿用占用兼容规则，并与同日真实规划去重。课程、设备日历、映射块不会按标题绑定待办。

## 安排与保存

点击安排先重新读取具体UUID和当前成员身份，然后进入原整页规划编辑器。先估时，再展示两个推荐并选中第一个；自定义查找仍默认五个并沿用避让记忆。截止早于目标日时提供查看／编辑待办，不自动延长截止。已有安排可查看，或显式追加；当前专注和异常任务不能直接追加。

编辑期间若他端增加未来规划，保存前询问查看已有安排或仍追加。确认仅认可已看过的安排快照，事务内再次复核身份、当前成员完成状态、删除／冲突／专注、目标日期及安排快照。确认后再次变化会拒绝写入并保留草稿。多个规划仍合法；失败不会写入半条规划或oplog，连点不会提交两次。

## 读取与刷新

查询只读，不运行旧Prefs迁移或清理，不访问设备日历、不逐项估时、不加载完整番茄历史。待办初始化未完成时提示返回首页加载后重试。

SQLite事务内完成稀疏投影、重复代表、分类、数量和游标分页。版本元数据每批最多200行，流式生成快照摘要；正常业务修改依赖既有version／updated_at递增。首屏最多解码50个清单待办。分页遇数据变化、规划／旧式区间结束或本地日界线变化会重读首屏，废弃旧游标。

页面绑定账号、成员ID、目标日期、筛选及请求序号。采用已有数据刷新、专注流和前台恢复通知；页面可见时仅设置下一规划／旧式区间结束或午夜的单次边界定时器。离页、进入编辑、后台暂停定时器；不后台轮询。返回清单保留筛选，成功保存后刷新状态。

只读承诺针对清单查询、筛选、打开／取消新规划草稿。查看原待办或返回原时间轴后的既有存储初始化、状态维护和显式编辑仍由原页面负责。
