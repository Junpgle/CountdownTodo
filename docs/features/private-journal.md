# 私密日记

私密日记按当前账号保存在本机，不参与云同步。

## 回收站

- 在日记详情选择“移至回收站”后，日记从时间线和照片墙隐藏，文字、日期、附件关系和照片文件继续保留在本机。
- 日记首页的回收站入口显示待处理数量。回收站按最近移入时间排列，可逐篇恢复或永久删除。
- 恢复使用原日记标识和原日期，不创建副本；恢复后日记重新出现在时间线和照片墙。
- 永久删除仅作用于当前账号中选中的回收站日记。确认后删除日记、附件记录和对应的本地照片；不提供批量清空或自动清理期限。
- 如果永久删除时有照片文件无法删除，数据库条目仍会删除，后续本机媒体清理会再次检查未引用文件。

## 编辑中的并发保护

如果日记已在编辑器打开，期间又从另一处移入回收站，旧编辑页面保存时会检查数据库状态并拒绝覆盖回收站状态。输入内容保留在编辑器中；先从回收站恢复后再保存。

回收站状态复用现有 `journal_entries.is_deleted` 字段，不新增数据库迁移、同步字段或服务端接口。
