# 快速语音 AI 对话

配置好 AI 对话模型后，按住主界面底部加号开始录音，松手后由 MiMo-V2.5-ASR
转写并发送到 AI 对话。
按住时向右上方拖动，提示“松手取消”，松手后丢弃录音，不调用识别接口。
向左上方拖动，提示“松手进入 AI · 保留草稿”，松手后转写并进入 AI 输入框，
由用户核对后手动发送；滑回普通区域可恢复松手发送。
AI 使用当前选择的对话模型理解需求，生成现有的操作确认卡片。
待办、日程、规划块等操作仍需确认；记账仍通过“编辑并保存”落库。
单击加号仍打开原有新增菜单。

## 新手指引

首页教程完成后，紧接着显示快速语音小节，高亮底部加号，依次说明按住录音、
右上划取消、左上划进入草稿和 API/麦克风准备。已经看过旧首页教程的用户只补看
语音小节；完成或跳过后不再自动显示。跳过首页教程时不会继续弹出语音小节。

## 配置

在“模型与 API 配置”的 API Key 配置中填写普通“小米 MiMo”密钥并保存。
语音识别固定使用普通 MiMo 的 `mimo-v2.5-asr`，不使用 MiMo Token Plan 密钥。
对话模型可以选择其他服务商，语音识别和意图处理分别使用对应密钥。
配置缺失时会提示前往配置；配置就绪后，接口的权限、余额和网络错误会在录音面板显示。

## 录音与后续对话

- 首次使用会申请麦克风权限；授权前松手会取消本次录音，授权后再次按住即可录音。
  拒绝后可从面板进入系统设置。
- 最长录音 60 秒，到时自动结束并识别。
- 取消或切到后台会关闭面板并释放麦克风，不提交 AI 对话。
- 识别失败可重试同一段录音，也可重新录音。
- 对话输入栏的麦克风按钮可以继续语音追问，沿用当前对话上下文。
- 已有文字草稿时，语音结果追加到草稿，供用户核对后手动发送。
- 原始录音仅暂存于内存；转写和回复沿用现有对话历史存储。
- ASR 返回的 `usage.seconds` 和 Token 用量进入现有 AI 用量记录。
- 录音容器从底部加号的实际位置展开，关闭时收回加号；遮罩和内容随容器渐变。
  动画沿用应用的时长和曲线，关闭动画、省电模式或系统减少动态效果时直接显示。
  波形随实际音量起伏；拖入目标时高亮、缩放并提供触觉反馈。
  系统开启减少动态效果时停用循环动画。
- 聊天输入栏的麦克风和无障碍长按入口保留按钮式录音，可点击“结束录音并发送”。

## 费用与记账

- 按 MiMo 返回的 `usage.seconds` 计算语音识别费，内置单价为 ¥0.5/小时，可在价格设置中修改。
- 转写文字下显示“语音识别”费用和录音秒数；AI 回复下分别显示所选对话模型费用。历史消息保留费用摘要。
- “AI 用量与费用”按录音时长显示 ASR 汇总和调用明细，与对话模型一起计入当月总费用。
- 开启“自动写入记账”后，同一月份、同一服务商与模型汇总成一笔“AI 服务”支出；重复刷新和对账不会新增重复账单。
- 服务端未返回秒数时标记待定价，不用 Token 或本地录音长度估算扣费。
- 重试 AI 回复不会重复记录已经发生的 ASR 费用；重新调用识别接口会产生新的识别用量。
- 金额按微元保存，自动账单按人民币分汇总，因此短录音可能显示费用但尚不足一分记账。

内置时长价格依据[MiMo 按量付费文档](https://mimo.mi.com/docs/zh-CN/price/pay-as-you-go)。
应用中的费用是按返回用量和配置单价计算的记录，实际扣费以 MiMo 控制台账单为准。

## 接口依据

按[MiMo 官方语音识别接口文档](https://mimo.mi.com/docs/zh-CN/api/audio/Speech-Recognition)
调用 `https://api.xiaomimimo.com/v1/chat/completions`，提交单条 WAV `input_audio`，
并设置 `asr_options.language=auto`。
录音采用 PCM16 流，按平台实际采样率和声道数封装 WAV。
输入字节上限为 7 MiB，确保 Base64 编码不超过官方 10 MB 限制。

Android 添加 `RECORD_AUDIO` 声明，iOS/macOS 添加麦克风用途说明，
macOS 的 Debug 与 Release 权限均包含 Audio Input。
Web 使用同一录音流路径，实际录音仍受浏览器麦克风权限及安全上下文限制。
