# 规划复盘与真实投入明细

第八轮在原“规划统计”入口内提供日／周／月概览、趋势、具体待办排行和可分页明细。概览使用主题色，常规手机两列，窄屏大字体改为单列，宽屏可四列；列数同时考虑宽度与字体，窄屏大字体日期使用短格式并保留完整日期提示。没有改变规划时间轴的高度或拖动手势。

## 数字的含义

- **真实规划**：本期开始、未删除、无冲突且起止／状态／正整数计划分钟数有效的数据库规划；取消、跳过单列，不计执行预算。课程、手机日历和旧式待办区间仍可在时间轴查看，不再伪造为统计规划。
- **已结束规划**：本期真实规划中已经结束、未取消／跳过的数量。完成只认真实finished状态；比例不代表待办完成度，也不再根据80%投入在统计页推断完成。业务层原有80%状态转换没有改动。
- **有效专注**：本期开始、已结束、未删除、无冲突、状态有效且实际秒数为非负整数的记录。中断和切换也可计投入，零秒不回退。旧记录缺失实际时长、坏时间或同步冲突单列核对，不用计划秒数补入实际。
- **时间日志**：与本期相交、结束时间不晚于当前时刻的有效日志，裁剪到范围后合计毫秒，再转秒格式化。未来结束的日志列入待核对，结束时刷新统计。日志可能彼此重叠，独立展示，不与专注相加。

规划、专注按本地开始日归属，跨午夜只计一次，不按墙钟跨度猜分实际专注秒数。日志按范围裁剪。日期边界使用本地日历日期构造。

## 关联与来源

每个专注UUID只计一次。核对显式规划ID、规划记录ID列表以及具体待办UUID；没有显式绑定时，只有唯一同待办重叠规划可以兼容关联。候选包含范围外开始的跨午夜规划；取消／跳过规划的已有投入仍保留。

关联竞争、悬空ID、矛盾身份或候选已删除／冲突会显示“归属待核对”，不能按标题猜测。实际记录合法时，其秒数仍只进入总量一次。已关联、未关联、归属待核对三类互斥且可以对账。

规划详情区分本期记录投入、累计记录投入和原累计参考。原累计缓存不参与实际总量。具体待办排行不折叠重复期次、不排除已完成待办；待办已删除／不存在时保留记录标题快照。

## 明细与处理

概览数字、排行和趋势可进入独立明细页；首屏50项，稳定起始时间／类型／UUID游标，手动加载更多。返回原记录详情时，若快照未变化保留已加载页及滚动位置；数据变化则刷新首屏。

专注和日志打开既有详情，保留标签名称。选择记录时重新核对账号／成员及记录存在性；最新记录失效则只展示原字段供核对。规划详情为独立只读展示，不经过时间轴的自动状态维护。

漏做保留原重新安排流程和保存前校验。尚未结束的异常missed标记只供核对，不提前生成漏做恢复提示。“复盘提示”为有依据的本地规则文案，可点开触发记录，不调用远程AI、不自动改期。

## 读取与刷新

`PlanReviewRepository`在同一SQLite读取事务内聚合、分组和取分页结果；只投影统计字段，不加载全部待办／番茄完整历史或逐规划查询。关联候选限制为范围内规划及当前记录相关规划；旧列表记录关联使用SQL检查，不将全部历史关联列表解码进页面。

游标指纹包含数据库连接身份、本连接写次数、其他连接data_version、账号成员、范围筛选、汇总和下一结束边界；发生写入或重开连接后废弃旧游标。页面请求序号防止旧响应覆盖新日期；存储刷新、专注状态、前台恢复及单次规划结束／午夜边界触发复核，离页或后台取消边界计时。

新读取不写待办、规划、记录、oplog或Prefs，不修复缓存，不迁移旧Prefs。未初始化的旧数据明确要求回原入口加载后重试。失败、无数据、筛选为空和待核对分别展示，不能用读取失败冒充零值。

本轮不改数据库结构、后端、同步协议、权限、专注计时、番茄统计或个人报告。番茄统计对旧记录仍可能回退为计划时长，统计口径说明中明确提示这一差异。
