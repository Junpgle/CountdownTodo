# 长任务分段规划

第十一轮功能，适用于同一个未完成待办的普通新建规划。已有规划编辑、冲突改期、漏做恢复保持原有单段流程。

## 使用

1. 在整页“新建规划块”中选择待办，点推荐时段下方的“分段安排”。总时长沿用当前编辑时长，包括首页入口已取得的AI估时；估时失败时先确认本次总时长。
2. 新页面只展示条件摘要和完整方案。点“修改条件”在弹窗设置日期、范围、总时长、单段上限、每日窗口、避让和前后缓冲。
3. 点“采用整组”回到新建页，此时只修改表单，没有写正式规划。每段列出真实起止和分钟数，间隔不会被算成占用。
4. 可“调整本段”移动起点并保持时长，或重新选择整组。“返回单段”恢复原单段时段，保留最新备注、提醒及番茄设置；放弃已调整分段需确认。
5. “保存全部N段”一次提交整组。“保存全部并开始第1段”先保存全部，再只启动首段，按首段自身时长或每段固定番茄轮数执行。

## 条件与计算

- 本次总时长30–720整数分钟；2–6段，每段至少15分钟。
- 单段上限默认45分钟，可选25／30／45／60／90／120或自定义15–120。
- 默认所选当天，可选从该日起3或7个自然日；不自动扩天、压缩时长或放宽条件。
- 每日窗口默认08:00–22:00。沿用账号记忆的午休、用餐、自定义避让及前后缓冲；当前明确的一次性选择保留在这次查询中。
- 返回最多5组完整方案。总和必须精确等于本次总时长，例如50分钟会重新分配短尾段，允许35＋15，不能生成45＋5。
- 占用来源与普通查找一致，包括课程、固定日程、有效规划及可读取的手机日历。全天／跨天手机事项仍不占用空闲；专注和时间日志仍属于实际投入信息。
- 新分段间隔至少为前后缓冲的较大值，例如前10后5，段间至少10分钟；避让区间不会再次加缓冲。
- 每段留在一个当地自然日窗口内，遵守待办定时或日期截止。时长用真实时间戳差计算，时区偏移帮助区分重复小时。
- 有界搜索优先较少段，结果按结束时间和起点稳定排序，不承诺全局最优。到运算上限明确提示“搜索未完成”，不能采用半组。

## 保存与暂存

采用和取消方案都不写正式业务数据。正式提交前重新读最新来源和待办；事务中再次检查账号／成员、完成状态、同步冲突、正在专注、截止、占用、草稿修订及追加安排确认。

所有分段及各自oplog在同一本机SQLite事务中提交。任一分段或日志失败，全部回滚。整组使用稳定目标UUID，完全相同的已保存目标可识别为重试；部分存在、修改、删除或冲突不会覆盖。成功后只发一次刷新／同步请求。

共同设置应用于每段，轮数标签为“每段番茄轮数”。固定轮数会显示本段实际专注分钟数，并提醒可能超过时段。后续分段不会自动开始。

本机规划草稿支持v2分段载荷，一组只占现有5份容量中的1份，仍有256KiB限制。v1单段草稿继续可读写。恢复保留真实时段与全部目标UUID，不自动估时或移到今天；恢复当前账号避让／缓冲默认，不保存日历快照及一次性放宽授权。时区变化须确认后保存。

保存后清理匹配修订的草稿；清理失败单独提示。再次恢复会检查全部目标，避免重复新建。各段保存后就是普通独立规划，继续支持拖动、撤销、改期、提醒、专注绑定和复盘。

本轮不改数据库结构、schema58、后端接口、同步字段、依赖或原生权限。本机整组事务不代表云端或手机日历跨设备原子预约，各段按现有协议独立同步。
