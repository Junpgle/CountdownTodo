# 第45轮方案：备份按数据域选择恢复

日期：2026-10-24（北京时间）

状态：**验收通过；已提交（未推送）。**

规划阶段按你的授权使用当前会话模型起草；当前会话没有指定或核验 GPT‑6.1 sol／中思考强度的入口。

## 1. 建议与收益

项目备份包含待办、规划、固定日程、专注记录、课表、习惯、记账、挑战和偏好设置。现在导入页会列出文件包含的数据类型与数量，但只提供团队数据处理选项；`DataImportService` 会处理备份中所有已支持的数据段。用户想只恢复账单、习惯或课表时，无法在导入页面排除其他模块，尤其无法避免把备份里的偏好设置一并应用到当前设备。

本轮建议让用户在导入前选择要恢复的数据域，并明确展示文件中各域的记录数量、软删除记录和不受当前版本支持的数据。默认选择文件中全部已支持的数据域，保留现有整包导入习惯；用户可以在确认前关闭不需要的部分。

## 2. 现有实现依据

- `DataExportService` 将各业务域分别写入 JSON `data`，导出页面可按类型选择；记账数据是包含分类、付款方式、账单、预算、周期规则、模板和贷款的完整 bundle。
- `DataImportPage._buildPreviewSection` 当前只显示导出时间、版本和每个数据段的数量，没有可选的恢复范围。
- `DataImportService.importDataFromJsonString` 会按 JSON 中出现的键逐项调用导入方法；包含 `settings` 时也会导入设置。
- 现有导入按 UUID 和更新时间合并，跨账号时会确定性重映射 UUID；待办、规划、固定日程和专注记录之间存在引用关系。导入失败时已有数据库与偏好设置回滚快照。
- `ImportPreview` 已有 `conflictCount` 字段，但当前文件解析不计算本地冲突；本轮不扩展逐条差异扫描，避免改变既有合并判定。
- 记账预览目前只累计账单、预算、周期规则、模板和贷款期次，没有计入 bundle 中的分类、付款方式。新预览应按完整 bundle 统计。

## 3. 批准后的用户行为

### 3.1 可选数据域

导入预览按以下数据域呈现复选框；每个域显示总数，并可展开查看组成记录数：

1. **待办、规划与专注**：待办分组、待办、倒计时、规划块、固定日程、时间日志、番茄标签和番茄记录。相关记录作为一个范围选择，避免跨账号导入时只映射一端而丢失待办／规划关联。
2. **课表**：课程数据。
3. **习惯与睡眠训练**：习惯目标、规则、打卡和睡眠训练计划，作为完整 bundle。
4. **记账**：分类、付款方式、账单、预算、周期账单、模板、贷款和期次，作为完整 bundle。
5. **30天挑战**：挑战状态及任务，作为完整 bundle。
6. **偏好设置**：单独列出，并说明选中后会应用备份中的设置到当前账号／设备。

文件中存在且受支持的数据域默认全选，以保持现有整包导入的默认结果。提供“全选”和“清空”操作；没有选中数据域时禁用导入按钮，服务层也拒绝空范围请求。

### 3.2 数量、删除状态和不支持内容

- 每个数据域展示归档记录总数及其中软删除记录数；展开后展示子类型数量。记账总数包含分类与付款方式，不只统计账单类数据。
- 明确说明软删除记录会参与现有合并逻辑，供同步恢复使用；用户可以通过取消整个数据域来排除，不把软删除项误标成普通活跃数据。
- JSON 中存在但当前版本不支持的数据段显示为“当前版本不会导入”，不提供勾选，也不计入预计导入数量。不能让原始键名和数量看起来像已支持导入。
- 预览和切换勾选仅解析文件，不写入数据库、偏好、提醒或同步队列。

### 3.3 导入规则

- 导入时只把所选数据域对应的 JSON 段交给现有导入流程，保留现有域内顺序、团队数据“跳过／转为个人”、同账号 UUID 保留、跨账号 UUID 重映射和按更新时间合并规则。
- 默认全选时，行为应与当前导入整个文件一致。偏好设置仍默认选中以兼容旧行为，但在范围摘要中单独突出显示；用户可以明确取消。
- “待办、规划与专注”作为一个范围，保持这几类数据间的 UUID 引用一起处理。其他数据域自身包含的子表或记录作为整体处理。
- 成功摘要统计所选数据域实际新增、更新和跳过的数量；未选择的数据域不出现在写入路径中。
- 保留现有导入回滚快照。所选范围任一导入阶段失败时，按当前策略回滚，并显示失败结果。

```mermaid
flowchart LR
    A[选择备份文件] --> B[只读解析与数据域预览]
    B --> C[选择要恢复的数据域]
    C --> D{至少选择一项?}
    D -- 否 --> E[禁用导入]
    D -- 是 --> F[过滤未选择的数据段]
    F --> G[现有合并流程与回滚保护]
    G --> H[显示新增、更新、跳过数量]
```

## 4. 范围与保护

- 只调整客户端的备份导入预览、范围选择、计数和 JSON 数据段筛选；必要时扩展 `ImportOptions` 与预览模型。
- 不改导出文件版本、数据库 schema、云同步协议、团队数据策略、跨账号 UUID 算法或各业务域的冲突合并语义。
- 旧版完整 JSON 仍可导入；缺少某些数据域时只显示文件实际包含的支持域。
- 不实现逐条冲突差异预览，也不提供单条记录筛选、删除策略编辑或导入后自动撤销入口。
- 偏好设置是独立选择项；取消后当前主题、提醒、首页和其他设置保持不变。

## 6. 验收标准

1. 解析完整备份后，所有支持的数据域按预期出现；默认全选时可以完成与当前相同的整包导入。
2. 只选择记账、课表或习惯时，仅对应域写入；未选中的待办、规划、专注、挑战及偏好设置保持逐项不变。
3. 选择“待办、规划与专注”后，跨账号 UUID 重映射保留待办、规划、固定日程及番茄记录间原本存在的可映射关联；不选该域时不写入该组数据。
4. 记账预览数量包含分类与付款方式；每个数据域正确标识软删除条目，不把无效／不支持数据段伪装成可导入内容。
5. 取消“偏好设置”后，导入前后的当前用户偏好完全一致；选中后按现有设置导入语义应用。
6. 未选任何数据域时页面按钮禁用，服务调用也返回明确失败，不产生数据库、设置、提醒和同步副作用。
7. 导入中任一阶段失败时回滚后各表与偏好保持原样；成功结果计数仅反映被选择的数据域。
8. 完成新增导入服务和页面测试、相关现有备份导入回归、静态分析、格式检查及 Web release 构建；提供手机与桌面界面截图，并报告未运行的验证范围。
