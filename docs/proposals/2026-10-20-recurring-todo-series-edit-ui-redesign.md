# 第25轮验收修正版方案：重复待办系列编辑界面整理

日期：2026-10-20（北京时间）

状态：**已实施，本地验收完成，待用户验收**。第25轮系列编辑的功能代码已提交为 `718d1dbf`，本方案修正该轮的界面与操作表达；用户确认修正验收通过前不开始第26轮。

## 1. 目标

让用户在编辑重复待办时能一眼看清三件事：正在修改哪个范围、会影响多少期、哪些状态和历史记录会保留。当前界面把范围说明、系列进度、期次选择、完成状态控件和重复规则堆在编辑表单前后；几种作用不同的操作也集中在同一个菜单里，信息重复且层级不明显。

本次只调整入口、版面和确认文案，保留第25轮已完成的数据范围、事务并发保护、待办状态、规划与专注记录语义。

## 2. 当前界面证据与问题

基线来自第25轮提交内的 `TodoEditScreen` 实际 Widget 渲染截图。截图使用合成待办数据，不含账户数据：

- 窄屏：[todo_recurrence_series_edit_phone.png](../../test/widgets/goldens/todo_recurrence_series_edit_phone.png)
- 日期变化确认：[todo_recurrence_series_edit_date_review_desktop.png](../../test/widgets/goldens/todo_recurrence_series_edit_date_review_desktop.png)
- 深色大字：[todo_recurrence_series_edit_dark_large_text.png](../../test/widgets/goldens/todo_recurrence_series_edit_dark_large_text.png)

截图与代码显示的具体问题：

1. 页面顶部先用长横幅说明“整个系列”和期次数量，紧接着又放一张“关联周期”卡片，重复展示期数、完成率、已完成/跳过状态和期次位置。
2. 横向期次卡片占据表单前的大块高度；其“点击其他期次可在本页切换编辑”说明没有说清切换后日期偏移以哪一期为基准。
3. 整系列模式仍显示灰化的完成状态开关，容易让人误以为可以批量改状态；重复规则又以禁用控件出现，底部另有说明，形成重复提示。
4. “保存”没有反映批量范围；日期变更复核以较长段落混排期数、偏移和历史保留说明，读起来不易扫视。
5. 重复管理菜单把三种编辑范围与“在本期结束循环”放在同级列表，编辑内容和停止后续生成的动作容易混淆。
6. 当前 golden 截图显示了 Flutter 调试角标和方框图标占位。它们可能来自 Widget 测试的渲染环境，不能据此断言正式运行版也有同样问题；本轮会修复测试预览设置并核验图标实际渲染，避免把测试装饰误当成产品界面。

## 3. 改版方案

### 3.1 重复管理入口按“编辑范围 / 系列操作”分组

编辑范围区改为三个清楚的选项：

- **仅本期**：只改当前这一期。
- **本期及以后**：修改当前和后续周期。
- **整个系列**：修改所有已生成期次；显示实际期次数量，并注明各期完成/跳过状态保留。

“在本期结束重复”移到独立的“系列操作”分组，使用分隔和说明：“停止后续生成；本期之后已生成的关联期次移入回收站”。这与现有行为一致。入口文案统一区分“编辑内容”和“停止重复”。不增加新的操作或改变现有作用范围。

### 3.2 编辑页顶部只保留一个影响摘要

将长横幅与完整进度卡收敛为一个紧凑的系列摘要：

- 主行显示“整个系列 · 3 期”。
- 次行显示“历史 1 · 当前 1 · 未来 1”及“完成 1 · 跳过 1”。
- 用小标签突出“每期状态保留”“重复规则不变”。
- 默认收起期次明细；点开“查看 3 期”后，使用紧凑列表呈现日期和完成/跳过/待办状态。
- 默认以打开编辑器时的期次作为日期偏移基准，并明确标注“日期变化以 10 月 20 日这期为基准”。如继续支持切换基准，切换控件放入期次明细中，标注“设为日期基准”，并在选择后同步更新摘要；未保存输入仍按已有退出保护处理。

### 3.3 表单只呈现可编辑内容

- 整系列编辑隐藏“完成状态”开关，改为摘要中的只读状态计数和一句“各期状态保持不变”。
- 重复规则显示为一行只读说明，例如“每周重复 · 本次不修改规则；调整规则请选‘本期及以后’”，移除重复的禁用编辑控件和底部重复提示。
- 标题、备注、日期/时间、分类、提醒和协作信息沿用现有字段与保存语义，分成清楚的内容、时间与提醒区块。
- 减少卡片套卡片，统一留白与边界；窄屏单列，桌面设置可读的最大内容宽度，不拉伸空白表单。
- 所有颜色从 Material 3 `ColorScheme` 取得；保留深色、高对比度、大字和滚动布局适配。

### 3.4 操作按钮和日期复核直说影响

- 编辑页主操作根据数量显示“应用到 3 期”，保存期间显示“正在保存…”。
- 只改文字等内容时，确认摘要显示期数、保留状态和不会改变的重复规则。
- 改日期/时间时，复核页使用分行结构：影响期数；首期和末期“原日期 → 新日期”；日期以哪一期为基准；规划块、专注记录和时间日志保留原时间。
- 取消始终是次要操作；确认按钮带上数量，例如“应用到 3 期”。
- 在提交按钮旁不额外添加“删除系列”或其它未批准能力。

## 4. 数据与行为边界

- 保持“仅本期 / 本期及以后 / 整个系列”现有语义和第25轮保存事务。
- 保持成员集合、每期基线及登录身份校验；任何并发变化仍整批拒绝并保留输入。
- 不改变 UUID、系列归属、完成/跳过状态、重复规则、协作权限和同步 oplog。
- 不移动或修改规划块、时间日志、番茄记录或系统日历事件。
- 不改数据库 schema、服务端、Cloudflare Worker、AI 操作协议、提醒调度和删除范围。

## 5. 验收标准

1. 重复管理入口把三种编辑范围和结束重复明确分组；每个范围描述能说明准确影响对象。
2. 系列编辑页首屏只有一个影响摘要，不重复展示完成计数；期次明细默认收起，展开后可识别日期基准与每期状态。
3. 整系列编辑不出现可操作或灰化的完成开关；重复规则仅用一个只读说明表达。
4. 保存按钮和日期复核均显示受影响期数；日期偏移的基准与首末期结果准确。
5. 标题、备注、日期、提醒、取消、保存失败、并发变化和整批保存仍通过第25轮行为回归。
6. 390×844/430×932 窄屏、1440×900 桌面、深色及至少 1.3 倍大字截图均无溢出、遮挡和横向挤压；图标显示正确，预览不带 Flutter 调试角标。
