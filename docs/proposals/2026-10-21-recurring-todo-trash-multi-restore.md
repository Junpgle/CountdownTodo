# 第29轮方案：回收站跨系列多选恢复

日期：2026-10-21（北京时间）

状态：**已批准并实施，等待用户验收**

## 1. 建议与收益

第27轮增加了单个重复系列整组恢复，第28轮增加了单个系列清理和回收站整体清理。现在如果误删了多个不同系列，或只想恢复多个系列中的部分期次，仍要逐个点恢复；整组恢复一次只能处理一个系列，也会恢复用户并不需要的期次。

建议在回收站增加“多选恢复”：可以跨普通待办和多个重复系列挑选准确的待办记录，再一次性恢复。恢复只影响选中的记录，不更改完成／跳过状态、重复规则、截止时间或规划内容。所有选中项在一次本地事务中恢复，遇到并发变化或保存错误时整批不落库，避免留下半批结果。

## 3. 用户操作流程

1. 仅在“已删除／回收站”页签增加“选择”入口，避免影响已完成、已跳过和孤儿待办的既有操作。
2. 进入选择模式后，每条回收站待办显示复选框；普通待办可单独选择。重复系列折叠卡片显示系列选择框，选择时从本地数据库读取该系列当前仍在回收站的全部期次；展开后仍可单独勾选或取消某一期。系列框支持全选、部分选择和未选三种状态。
3. 已选项目可以跨多个系列和分页累积。底部操作条显示准确的已选条数，提供“取消选择”和“恢复所选”。更换搜索词不丢弃已选项，已选总数持续可见；退出选择模式会清空本次临时选择，不写入待办数据。
4. 点击“恢复所选”先展示确认摘要：待办条数、涉及系列数、日期范围，以及原本已完成／已跳过的条数。确认文案说明只恢复已选记录，完成状态、跳过状态和重复规则保持原样。
5. 成功后退出选择模式、刷新回收站和首页待办，显示恢复数量。并发校验失败时刷新列表、移除已失效的选择并保留其余选择；数据库／oplog 写入失败时保留当前选择供重试。两种情况都不能显示“部分成功”。

## 4. 数据与一致性规则

- 新增批量恢复计划／执行服务，接收去重后的待办 UUID 和确认时读取的版本基线；执行时重新查询所有目标，必须仍存在且仍在回收站。任何一项消失、已恢复或版本已变更，则整批拒绝，不恢复其他项。
- 只将选中记录的 `is_deleted` 设为 `false` 并更新版本与时间戳；复用当前单条恢复的失效分组修复规则。其余待办字段保持不变。
- 恢复行与对应待办本地 oplog 操作放在同一个 SQLite 事务中；事务失败或任一 oplog 写入失败时全部回滚。成功后仅清除被恢复重复期次的本地去重墓碑，并触发待办、日程冲突及相关首页刷新。
- 不改变重复规则、不自动补齐未选期次、不覆盖同系列其他记录；也不修改已存在的规划块、专注记录、时间日志或待办完成状态。
- 保留现有逐条恢复和单系列整组恢复入口。永久删除、清空回收站、服务端协议和数据库 schema 均不在本轮范围内。

## 5. 界面与无障碍

- 选择模式沿用当前 Material 3 主题色与回收站卡片样式，底部操作条避开系统手势区；不新增常驻占位按钮。
- 系列卡片的三态选择明确表达“该系列全部／部分／无期次被选中”，系列选择只针对当前仍在回收站的期次。
- 在手机窄屏、桌面宽屏、深色主题和大字号下检查复选框触控范围、摘要换行、底部按钮和长标题；屏幕阅读器标签说明系列选择范围及三态。

## 6. 本轮不包含

- 跨实体恢复倒计时、课程、时间日志或习惯项目。
- 多选永久删除、清空回收站或把批量选择保存成长期草稿。
- 批量编辑待办内容、截止时间、文件夹或重复规则。
- 修改服务器端权限、协议或同步格式。

## 7. 验收计划

1. **选择范围**：跨普通待办、两个以上重复系列和不同分页选取记录；系列全选后取消一条，确认三态、数量和范围准确。
2. **恢复结果**：恢复选中记录后逐条核对 `is_deleted`、完成／跳过状态、日期、重复规则、文件夹和其他字段；未选中的同系列记录保持原样。
3. **重复维护**：恢复后执行重复维护，确认被恢复期次不重复生成、未选中的已删除期次不会复活，规则仍只有预期的活动承载项。
4. **并发保护**：确认期间任一选中项被恢复、删除或修改时，整批不产生部分提交并给出可理解提示；重复点击不重复写入。
5. **故障回滚**：模拟目标校验、数据库事务和同步操作写入失败，确认所有选中项仍保持原状态，列表可重载且没有成功提示。
6. **显示与选择状态**：验证搜索变化、继续加载分页、展开／折叠系列、退出选择模式和空列表；截图覆盖手机确认与成功、桌面选择模式、深色大字布局。
7. 运行新增服务／存储测试、回收站 Widget 测试、重复删除与整组恢复回归、相关静态分析、`flutter build web --release --no-pub` 和 `git diff --check`。
