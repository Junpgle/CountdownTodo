# assets/ — 静态资源目录

## 📌 目录构成

存放应用所需的图标、图片、启动页资源以及功能引导媒体文件。

---

## 📂 目录索引

| 目录 | 职责 |
|------|------|
| `icon/` | 应用图标（全平台） |
| `images/` | 内置壁纸、勋章图标、占位图 |
| `splash/` | 启动页静态图与动画资源 |
| `guide_media/` | 新功能引导中使用的演示视频或图片 |
| `turnstile/` | 原生 WebView 人机验证页面资源 |

---

## ⚠️ 使用规范

1. **资源注册**: 目录已在根目录 `pubspec.yaml` 中按目录声明；新增顶层资源目录时必须同步注册。
2. **图片优化**: 建议先进行无损/有损压缩再放入，单个文件尽量不要超过 500KB。

---

根目录另有 `splash/` 与 `wallpaper/` 资源树，不应与本目录下的同名用途混淆。
